# Farm 02 art

- `cerrado-diorama.png` is a generated static environment layer for the Farm 02 Cerrado scene. It contains the terrain, road, water reservoir, structures, vegetation and fences; it contains no cattle. Interactive cattle are separate sprites under `assets-source/nelore/` and the navigation geometry is separately authored in `src/simulation/farm02-navigation.ts`.
- Generated with the built-in image generation tool for this project. The editable master is 1536×1024 RGBA; the lossless editable master stays as PNG; a high-quality WebP runtime copy is served from `static/assets/farm-demo/cerrado/` (about 79% smaller).
