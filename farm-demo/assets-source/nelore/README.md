# Farm 02 cattle sprites

- `nelore-master.png` is the generated transparent Nelore-inspired sprite master.
- Runtime sprites are cropped and normalized copies with small stable coat-lightness variations. They remain separate scene entities, so positions, selection and movement come from the shared simulation rather than the artwork.
- The sprite set and the farm scene use the same pixel-art renderer and are loaded from `static/assets/farm-demo/nelore/`.
